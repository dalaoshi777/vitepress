## 注释

## 单行注释

```javascript
// 这是单行注释
let a = 1; // 行尾注释
```

## **多行注释**（块注释）

```javascript
/*
这是
多行注释
*/
let b = 2;
```

## **文档注释**（常用在函数 / 类上方，配合编辑器提示）

```javascript
/**
 * 求和函数
 * @param {number} x 第一个数
 * @param {number} y 第二个数
 * @returns {number} 结果
 */
function add(x, y) {
  return x + y;
}
```
